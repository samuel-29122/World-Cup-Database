# World Cup Database

## About the Project

This project is part of the freeCodeCamp Relational Database Certification.

I created a PostgreSQL database containing information about World Cup matches from 2014 and 2018.

## Technologies Used

- PostgreSQL
- SQL
- Bash scripting
- GitHub Codespaces

## Project Features

- Created a `worldcup` database.
- Created `teams` and `games` tables.
- Used primary and foreign keys to connect the tables.
- Imported match results from a CSV file using a Bash script.
- Wrote SQL queries to retrieve and analyse match information.

## Files

- `worldcup.sql` – Contains the database structure and data.
- `insert_data.sh` – Imports World Cup match data into the database.
- `queries.sh` – Runs SQL queries to retrieve information.

## What I Learnt

This project helped me understand how relational databases work, how tables are connected using keys, and how SQL queries can retrieve information.

I also gained experience using PostgreSQL and Bash scripts through the terminal.
